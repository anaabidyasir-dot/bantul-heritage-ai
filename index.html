Tentang Proyek / About This Project

🎯 Tujuan / Purpose

Bantul Heritage AI dibuat untuk memudahkan akses terhadap informasi budaya lokal Kabupaten Bantul bagi pelajar, guru, wisatawan, dan masyarakat umum.

Built to make Bantul's local cultural knowledge accessible to students, teachers, tourists, and the general public.

⚠️ Keterbatasan / Limitations

  • Mode demo hanya mencakup ~20 topik budaya
  • Jawaban demo adalah teks yang sudah disiapkan, bukan AI generatif
  • Integrasi Gemini AI memerlukan konfigurasi API key terpisah
  • Konten bersifat informatif dan belum menggantikan sumber akademis resmi

🔒 Privasi / Privacy

Aplikasi ini tidak menyimpan data percakapan Anda. Dalam mode demo, semua pemrosesan terjadi di browser Anda sendiri. Tidak ada data yang dikirim ke server.

No conversation data is stored. In demo mode, all processing happens in your browser. No data is sent to any server.

📚 Sumber / Sources

Konten demo disusun berdasarkan informasi budaya yang tersedia secara publik tentang Kabupaten Bantul, DIY. Semua jawaban diberi label tingkat kepercayaan yang jelas.

Demo content is based on publicly available cultural information about Bantul Regency. All answers are clearly labeled with a trust level.

🤝 Komitmen AI Bertanggung Jawab / Responsible AI Commitment

Bantul Heritage AI berkomitmen untuk: selalu membedakan fakta terdokumentasi dari informasi yang belum terverifikasi, bersikap jujur ketika tidak dapat menjawab, tidak mempublikasikan pengetahuan tradisional yang bersifat terbatas, dan menghormati nilai-nilai budaya lokal.

🔑 Konfigurasi Gemini API Key

Masukkan API key Google Gemini untuk mengaktifkan Mode Live AI. Tanpa API key, aplikasi tetap berfungsi dalam Mode Demo.

Cara mendapatkan API key gratis:
  1. Buka aistudio.google.com
  2. Login dengan akun Google
  3. Klik "Get API key" → "Create API key"
  4. Salin dan tempel di sini

API key tidak akan disimpan secara permanen dan tidak dikirim ke server selain Google.

🔒 Keamanan: API key hanya disimpan di sessionStorage browser Anda dan hilang saat tab ditutup. Jangan bagikan API key kepada siapapun.
